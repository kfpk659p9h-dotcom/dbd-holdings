DBD HOLDINGS LLC — V2

PREVIEW
Open index.html in this folder. Keep the assets folder, styles.css, script.js and contact.vcf beside it. The separate standalone index.html supplied with the ZIP embeds everything and works offline.

PUBLISH ON GITHUB PAGES
1. Sign in to GitHub and create a public repository named dbd-holdings (or open your existing website repository).
2. Extract this ZIP. Upload the CONTENTS of the dbd-holdings-v2 folder to the repository root: index.html, styles.css, script.js, contact.vcf and the entire assets folder. Do not upload only the enclosing folder or the ZIP.
3. In repository Settings → Pages, select Deploy from a branch, choose main and / (root), then Save.
4. When GitHub shows the site address, open it and check the photos, menu, email, phone, and Save contact button. Publishing can take a few minutes.
5. For your domain, enter the exact domain you own under Settings → Pages → Custom domain. At your domain provider, follow GitHub's current DNS instructions linked below. Enable Enforce HTTPS once available. Your business email alone does not establish which website domain you own.
6. Keep existing email DNS records (MX, SPF, DKIM and DMARC) intact when changing website DNS.

GitHub's official instructions:
https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site
